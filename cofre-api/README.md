# Cofre

É o sistema por trás de uma carteira digital.

## O problema

Criar uma conta;
Depositar dinheiro;
Sacar dinheiro;
Transferir para outra conta;
Ver o extrato (o histórico de movimentações).

## Regras de negócio
- Quando uma operação deve ser recusada?
- Saldo negativo;
- Saque negativo ou igual a zero;
- Transferência para a mesma conta;

## Stack planejada
Java 26, PostgreSQL, Spring Boot.

Em construção. Etapa atual: nada.
